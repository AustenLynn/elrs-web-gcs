Two runs of about 19,560 commands each, flown from the same laptop: one on the local Wi-Fi, one through the Cloudflare tunnel. Every number here comes from the per-command logs of the browser, the gateway and crsf-core.

The two runs side by side

Total = network + gateway + core, from the browser's send to the full 26-byte serial write. "Within 50 ms" counts every command the browser sent, and adds the clock-sync uncertainty (RTT/2) before comparing. Through the tunnel RTT/2 is about 30 ms, so no command can be shown under 50 ms with that margin, even though the estimate puts 91 % there.

Process capability against the 50 ms limit

Only an upper limit exists (latency has no lower limit), so the indices are one-sided: Ppk = Ppu. Common targets: 1.33 is capable, 1.67 is good. Calculated on the commands that reached the radio; the commands that never did are in the attribute row of the first table.

Which index to quote

The data fails the normality test badly (A² in the thousands) and has a long right tail from Wi-Fi bursts. The normal Ppk assumes the tail away and predicts almost no command over 50 ms, while 696 per million actually were (local). Quote the percentile (ISO) Ppk, which uses the data's own 99.865th percentile, and show the observed PPM next to it.

Local against tunnel

Mann-Whitney compares the two distributions without assuming normality (the right test for this skewed data). Box = Q1 to Q3, line = median, whisker from the minimum to p99, dot or arrow = maximum.

How to read these results in the report

Local Wi-Fi qualifies

95.44 % of all 19,558 sent commands reached the serial port within 50 ms including clock uncertainty (95 % CI 95.14–95.72 %). The software adds about 2 ms (gateway 0.05 ms, core 2 ms); the rest and all the spread is Wi-Fi.

The tunnel costs about 29 ms

The median rises from 4.5 to 33.2 ms, almost all of it in the network segment. The tunnel run is a comparison, never a qualifying run: the criterion requires local routing, and its clock uncertainty (about ±30 ms) is too large to prove any command under 50 ms.

Where it stops

All figures end at the serial write on the Pi. The TX module, the radio and the drone are not included.
